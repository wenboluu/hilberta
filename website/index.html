Evaluation settings and full-precision data

Matched initial latents, 28 steps. KID reports mean ± subset standard deviation, not a confidence interval. Best values use unrounded numbers and do not imply statistical significance.

Seed 2707, guidance 7.5. CLIP: ViT-L/14 cosine similarity. LPIPS: AlexNet, images resized to 512. PSNR and SSIM: original resolution. FID/KID: torch-fidelity, 100 KID subsets of 1,000 images. The evaluation set has some overlap with early diagnostic captions.

CLEAR uses official local16. SpargeAttn uses top-k 0.25 with INT8 Q/K and FP8 V; our attention is BF16. Configurations were selected for speed among those tested, not an exhaustive quality–speed comparison.

Benchmark scope and all measurements

Denoising time uses cached text and excludes VAE decoding and file writing. Attention is only part of the denoiser, so kernel speedup does not translate directly to generation speed.

Kernel latency is phase-weighted across 57 layers, using resident Q/K/V and metadata. Denoiser timing includes one transformer forward. Reported performance uses the paired inference kernel with merged BF16 LoRA. Quality at 1024 used Flex64; 2048 generation used paired. Stage 3 reuses stage-2 speed measurements.

The same benchmark harness was used for all methods, with warm-up and compilation excluded. Fixed tile counts do not imply linear complexity. There is no quality evaluation at 4096.

Code & reproduction

The code includes inference, kernels, training and evaluation tools, pinned dependencies, and correctness tests. Start with 4 tiles / K1; use 16 tiles / K3 for more speed.

Trained LoRA weights are not yet available. The base model alone does not reproduce the reported quality. The new portable training runner has not yet reproduced the historical training runs.
