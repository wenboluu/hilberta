FLUX sparse attention, stage 3: 2048 x 2048 LoRA fine-tuning and evaluation (Full FLUX / ours 4-tile K1 / ours 16-tile K3 / CLEAR local16 / SpargeAttn topk0.25)

Every number is measured unless a cell says MISSING / n/a; missing inputs are reported, never invented. No plots; image comparisons are HTML pages. Protocol: the same 2,048 COCO val2017 prompts and real-image reference as stage 2; seed-2707 initial latents built at 2048 (initial_latent(seed, device, 2048, 2048)), 28 steps, guidance 7.5, true CFG 1, max_sequence_length 512, cached text embeddings. Competitors are the configurations chosen in stage 2 (no re-screening), run with their official code at 2048.
